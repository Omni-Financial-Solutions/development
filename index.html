Developers

Payments API, without the archaeology

One integration for online checkout, payment links, invoices and in-app payments. Test keys in minutes, idempotent by default, webhooks for everything.

  • Drop-in Omni Checkout, or fully custom with the Payments API
  • RenPay as a payment method with one extra line
  • Sandbox that mirrors production, including payouts to Renda
npm i @omni/payments
curl https://api.omni.renda/v1/payments \
  -u omni_test_••••••••: \
  -d amount=4850 \
  -d currency=cad \
  -d source_id=card_••••4242 \
  -d idempotency_key=order_1043
import Omni from "@omni/payments";

const omni = new Omni(process.env.OMNI_KEY);

const payment = await omni.payments.create({
  amount: 4850, currency: "cad",
  orderId: "order_1043",
  payout: "renda:smart-spend",
});
// Offer RenPay alongside cards
checkout.paymentMethods([
  "card", "apple_pay",
  "renpay_qr",   // ← scan, confirm, paid
]);
